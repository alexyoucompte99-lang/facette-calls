Facette · Les appels à venir

L'onglet qui liste tous les rendez-vous posés et prépare les relances WhatsApp, pour le dashboard dashboard-facette.vercel.app.

1. L'utiliser tout de suite (Alex)

Glisse ce bouton dans ta barre de favoris. Ensuite, sur le dashboard, clique le favori : l'onglet apparaît sous les cartes de coût.

📞 Appels Facette

Si le glisser-déposer ne marche pas : nouveau favori, et colle ce texte comme adresse.

javascript:(function(){var s=document.createElement('script');s.src='https://alexyoucompte99-lang.github.io/facette-calls/loader.js?'+Date.now();document.body.appendChild(s)})();

Ça ne modifie rien sur le site de Léo : le code se charge dans ta page, avec ta session déjà ouverte. À refaire à chaque ouverture du dashboard, jusqu'à ce que Léo l'intègre.

2. L'intégrer dans le dépôt (Léo)

Trois fichiers, aucune modification de app.js. Rien à ajouter côté API ni SQL : l'onglet lit /api/leads et /api/funnel avec la session en cours.

  1. Copier appels.js et appels.css à côté de app.js.
  2. Dans index.html, dans le <head> : <link rel="stylesheet" href="appels.css">
  3. Coller le contenu de section.html juste après <section class="grille-kpi" id="kpi-argent" …></section>
  4. En bas, après <script src="app.js"></script> : <script src="appels.js"></script>
  5. Déployer.

Ce que fait l'onglet

  • Chaque rendez-vous posé dans Créno, jour par jour, heure de Paris, compte à rebours.
  • Le prospect : nom, téléphone, e-mail, cabinet, ville, score global / Google / IA, place sur Google, corrections, ligne du cabinet, date de réservation, pub d'origine.
  • 4 messages WhatsApp déjà écrits avec ces données : confirmer le créneau, poser une question, rappel 1 h avant, il n'a pas répondu. Le bon est marqué « conseillé » selon l'heure. Texte modifiable, bouton WhatsApp et Copier.
  • Suivi « message envoyé » / « il a confirmé », mémorisé sur le navigateur.
